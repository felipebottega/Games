## set_navigation_layer_value() e get_navigation_layer_value()

As únicas novidades que vale a pena mecionar são as funções `set_navigation_layer_value()` e `get_navigation_layer_value()`. Muitos nodes relacionados à navegação possuem as funções `set_navigation_layer_value()` e `get_navigation_layer_value()` para definir e para obter um número de camada diretamente, sem a necessidade de operações bit a bit mais complexas.
