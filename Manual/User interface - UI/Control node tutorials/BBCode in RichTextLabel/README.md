# BBCode in RichTextLabel

Por padrão, o `RichTextLabel` tem as mesmas funções que um `Label` normal, mas o `RichTextLabel` utiliza [BBCode](https://www.bbcode.org/reference.php), um sistema de tags que definem regras de formatação para uma parte do texto. BBCode também é conhecido como *bulletin boards*, daí o "BB" em "BBCode". Já mencionamos BBCode [neste tutorial](https://github.com/felipebottega/Games/tree/gh-pages/Manual/Scripting/Core%20features/Debug/Output%20panel#printando-mensagens), [neste](https://github.com/felipebottega/Games/tree/gh-pages/Manual/Scripting/GDScript/GDScript%20reference#coment%C3%A1rios) e [neste](https://github.com/felipebottega/Games/tree/gh-pages/Manual/Shaders/Shading%20reference/Shading%20language#coment%C3%A1rios).

Ao contrário do `Label`, o `RichTextLabel` possui sua própria barra de rolagem vertical. Essa barra de rolagem é exibida automaticamente se o texto não couber no tamanho do controle. A barra de rolagem pode ser desativada desmarcando a propriedade *Scroll Active* no *Inspector*.

## Básico de BBCode

Para poder utilizar o BBCode, é neecssário habilitar a propriedade *BBCode Enabled* no *Inspector*. Feito isso, um exemplo mínimo de teste seria escrever "*I am [color=green]BBCode[/color]*" na caixa de texto. O efeito é imediato no editor, não precisa executar o jogo.

<p align="center">

</p>

A maioria dos códigos BBCode consiste em três partes: 

- **Tag de abertura:** A tag de abertura delimita o início da parte formatada e também pode conter opções de configuração. Algumas tags de abertura, como a de cor mostrada acima, também exigem um valor para funcionar. Outras tags de abertura podem aceitar várias opções (separadas por espaços dentro da tag de abertura).
- **Conteúdo:** É o que de fato será mostrado como texto na tela.
- **Tag de fechamento:**  A tag de fechamento delimita o fim da parte formatada. 

> PS: Em alguns casos, tanto a tag de fechamento quanto o conteúdo podem ser omitidos.

### URLs

Por default, a tag `[url]` não faz nada quando clicada. Para obter esta funcionalidade, é necessário criar o sinal `meta_clicked`. O comando `OS.shell_open(str(meta))` no sinal garante a conexão com a url através do sistema operacional.
